# H2 LCOH Pipeline — NE Brazil vs N Germany

## Persistent Memory Workflow
1. **Mandatory initial context:** before starting any investigation, refactoring, or new pipeline stage, consult `docs/memory/README.md` and read the modular reference file(s) relevant to the area being touched.
2. **Mandatory documentation update:** any structural, methodological, or configuration change must update the relevant file(s) in `docs/memory/` and `docs/memory/README.md` in the same unit of work that makes the change. A memory file that no longer matches the code it describes is worse than no memory file.
3. **Source of truth:** real code in `src/`, `config/`, and `tests/` always overrides documentation — including `docs/memory/`, `ARCHITECTURE.md`, and `METHODOLOGY.md` — when they disagree. Flag the discrepancy and fix the documentation rather than propagating a stale assumption.

## Stack
Python 3.11 | rasterio, geopandas, rasterstats, numpy, scipy, pydantic, matplotlib, requests, python-dotenv | pytest

## Structure
- `src/acquisition/` — ALL network requests. Nothing else touches the network.
- `src/spatial/`    — GIS pipeline (layers → exclusion → TOPSIS/VIKOR → sites)
- `src/economics/`  — LCOH model, decomposition, incentive scenarios
- `src/potential/`  — H2 potential from retained sites
- `src/sensitivity/`— OAT sensitivity + TOPSIS weight perturbation
- `src/viz/`        — All plots
- `config/`         — scenario_params.yaml (all numeric params) + config_loader.py
- `data/raw/`       — Written by acquisition/ ONLY. Never by hand.

## Commands
- `python run_pipeline.py` | `python test_quick.py` | `pytest tests/`

## Hard Rules
1. CRS: NEVER hardcode. ALWAYS `RegionCRS.projected_crs_for(region)` → custom Albers Equal Area Conic PROJ4 per region (not EPSG:31984/25832 — see `docs/memory/04_spatial_methodology.md` for why)
2. Region keys: NEVER raw strings. ALWAYS `Region.NORDESTE_BR` / `Region.NORTH_GERMANY`
3. Config key translation: ONLY in `_config_helpers.py`
4. Numeric params: ONLY in `scenario_params.yaml`. No module reads YAML directly except `config_loader.py`
5. Network: ONLY in `src/acquisition/`. Every module exposes `fetch(region, config) -> Path`
6. Missing credential: fail explicitly with message. Never proceed silently.
7. Each stage writes to disk before next stage reads.

## Do Not
- Hardcode CRS strings or numeric parameters
- Make network requests outside src/acquisition/
- Write to data/raw/ from any module except acquisition/
- Read scenario_params.yaml except via config_loader.py
- Add dependencies not in requirements.txt without flagging

## Git Commit Rules
- Write objective, clean commit messages describing what changed and why, in plain English.
- Strictly prohibited: AI signatures, "Generated by Claude" or equivalent tool attributions, Co-authored-by tags referencing an AI tool, and emojis. Commits must read as if written directly by the research team.
